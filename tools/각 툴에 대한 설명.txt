시스템 UI 수정 부분
1.시스템 메뉴 편집 툴 (툴01)로 mask export(export TSV/PBM)

2.이후 추출된 mask 한글로 수정(그림자 넣을 생각이면 그림자 포함)

핑크 : 255, 90, 180 - #ff5ab4 <- 이게 그림자 색(팔레트 index 1)
흰색 : 255,255,255 - #ffffff <- 글자 색(팔레트 index 2)
녹색 : 0,255,0  - #00ff00 <- 배경 색(팔레트 index 3) : 이 부분은 나중에 색 변경이 필요한 부분
하늘색 :  90,170,255 -    <-추후 배경을 이 색으로 변경해야함(이미지 색 분리 후)

3.팔레트 index에 개별적 적용을 위한 툴 (툴04)을 통해서 팔레트 index 1-3까지 추출(단순 메세지 창일 경우)
리소스 id는 상황에 맞게 넣어서 추출

4.한글 수정이 완료된 mask는 (3.)에 적용하기 위해 색상 분리 툴 (툴15)에 넣어서 이미지를 분리. 이걸 3에서 추출된 명칭과 동일하게 변경
배경 3인 경우 녹색을 -> 하늘색으로 변경 후 저장

5.4에 적용된 이미지를 3에 추출된 위치에 덮어쓰기

6.팔레트 index에 개별적 적용을 위한 툴 (툴04) 수정된 내용 반영

7. 이후 테스트 진행
