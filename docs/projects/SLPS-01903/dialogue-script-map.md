## Notes

- `entry word` is the start word from the script resource's entry pointer table.
- `opcode word` is where the approximate parser found opcode `0x41`.
- When `entry word` and `opcode word` differ, that entry contains earlier
  opcodes before the dialogue call.
- `segments` is read from the message bank header at `commonBuffer + 0x1930`.
- `reveal entries` is `segments * 14`, matching the table generated by
  `0x8017CC90`.
