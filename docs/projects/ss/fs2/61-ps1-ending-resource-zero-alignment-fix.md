# PS1 엔딩 resource 0 타일맵 정렬 수정

## 증상

PS1 엔딩 GUI에서 resource 0을 추출하면 화면 앞부분이 뒤로 밀려 표시됐다. SS판 resource 0에서 확인했던 현상과 동일하다.

## 원인

- 화면: 37×3 타일, 즉 타일맵 111항목/222바이트
- 실제 타일맵 시작: `0x210`
- 타일 데이터 시작: `0x2F0`
- 타일맵 뒤에 4바이트 정렬을 위한 2바이트 패딩이 존재한다.

기존 PS1 범용 파서는 `tileDataOffset - mapBytes`로 시작점을 계산해 `0x212`를 사용했다. 이 때문에 타일맵을 한 항목 뒤에서 읽었다.

## 수정

`scripts/be-hdr-ui-tile-tool.js`의 헤더 판정에 다음 규칙을 추가했다.

- `align4(0x210 + mapBytes) == tileDataOffset`이면 타일맵 시작은 `0x210`
- `align4(0x10 + mapBytes) == tileDataOffset`이면 타일맵 시작은 `0x10`
- 두 형식이 아니면 기존 계산을 사용한다.

## 검증

- resource 0 추출 결과가 `あなたはどこへ行きたいですか？` 순서로 정상 표시된다.
- PNG 왕복 변경 픽셀: 0
- 재패킹 변경 타일 슬롯: 0
- 고유 타일 107개, 용량 116개
- GUI 대상 resource `0, 1, 2, 11, 12, 14, 15, 16, 18, 19, 20, 21` 전체 추출 성공

기존 작업 폴더의 resource 0 파일은 잘못된 오프셋을 사용했으므로 GUI에서 `1. 편집 PNG 추출`을 다시 실행해야 한다.
