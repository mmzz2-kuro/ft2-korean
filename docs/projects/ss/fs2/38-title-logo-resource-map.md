# 38. 타이틀·로고 리소스 대응 조사

## 대상

PS1 로고 작업 흐름에 기록된 리소스 `251`, `288`, `287`, `300`을 SS 전체 리소스와 비교했다.

- 도구: `scripts/ss-fs2-map-logo-resources.js`
- 결과: `output/ss-fs2-logo-resource-map.json`
- PS1 최신 데이터: `output/patched-farland-saga-logo.bin`에서 추출한 DAT

## 대응 결과

| PS1 ID | SS ID | 화면 | 원본 관계 | 최신 PS1 변경 |
|---:|---:|---:|---|---|
| 251 | 222 | 320×240 | 할당 영역 완전 동일 | 있음 |
| 288 | 259 | 320×240 | 구조·팔레트·크기 동일, 원본 그림 다름 | 있음 |
| 287 | 258 | 104×32 | 할당 영역 완전 동일 | 없음 |
| 300 | 271 | 144×48 | 할당 영역 완전 동일 | 없음 |

이 구간의 대응 규칙은 `SS ID = PS1 ID - 29`다. 기존 UI/이름 구간의 `-114` 규칙과 다르므로 리소스 범위별 대응표를 사용해야 한다.

PS1 `251`과 SS `222`는 39섹터 전체가 같다. PS1 `288`과 SS `259`는 둘 다 40×30타일, 320×240픽셀, tile data offset `0xB70`, 39섹터이며 팔레트도 같다. 두 번째 화면은 원본 표시 그림만 다르다.

최신 PS1 통합판에서 `287`, `300`은 원본과 같으므로 이식 대상이 아니다.
