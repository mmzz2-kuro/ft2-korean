# 49. SS be-hdr 팔레트 인덱스 검사기

## 목적

PS1용 `tools/behdr_palette_inspector_gui.py`와 같은 방식으로 SS 최종 Track 1 안의 be-hdr 리소스를 직접 검사하는 GUI를 추가했다. 팔레트 레이어 후처리 전에 글자, 그림자, 배경, 그라데이션이 사용하는 인덱스를 화면의 특정 영역에서 확인할 수 있다.

## 실행

```powershell
python tools/ss_fs2_behdr_palette_inspector_gui.py
```

기본 입력은 다음 최종 빌드다.

```text
output/ss-fs2-korean-final-track1.bin
```

리소스 ID 입력란에는 보류된 `714`, `1073`, `1074`, `1087`, `1088`이 목록으로 제공된다. 입력란은 직접 수정할 수 있으며 다른 SS be-hdr 후보도 읽기 전용으로 검사할 수 있다. 이미지 형식이 be-hdr 8bpp 타일형이 아니면 추출 단계에서 오류로 중단된다.

## 기능

- SS BIN 내부 리소스 테이블에서 ID의 LBA와 길이 자동 계산
- raw 8bpp 팔레트 인덱스 화면 추출
- 50%, 100%, 200%, 400%, 800% 확대
- 픽셀 클릭으로 좌표와 팔레트 인덱스 표시
- 영역 드래그로 선택 범위의 인덱스 분포 표시
- 전체 화면 인덱스별 픽셀 수와 비율 표시
- 디버그 색상화 PNG 저장

색상화 화면은 실제 게임 CLUT 색상이 아니라 서로 다른 인덱스를 눈으로 구별하기 위한 디버그 색상이다. 실제 색은 게임의 팔레트 상태와 애니메이션에 따라 달라질 수 있으므로, 레이어 번호를 찾을 때는 색 자체보다 클릭·영역 히스토그램의 인덱스 값을 기준으로 한다.

## 검증

최종 SS Track 1에서 리소스 `1087`을 실제로 읽었다.

```text
화면 크기: 512×144
타일 용량: 667
raw PGM 생성: 성공
GUI Python 구문 검사: 성공
```

검사기는 BIN을 수정하지 않는다. 확인한 인덱스는 48단계 팔레트 후처리 GUI의 리소스별 인덱스 입력란에 사용한다.
