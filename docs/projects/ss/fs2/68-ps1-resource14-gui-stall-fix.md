# PS1 리소스 14 GUI 정지 현상 수정

## 원인

`ps1-fs2-resource-14-ko-edit.png`가 있으면 GUI가 이를 실제 런타임 프레임으로 이관하기 전에 기존 BE-HDR 리소스 14에도 패킹하려 했다.

한글 수정본은 고유 타일 286개가 필요하지만 기존 BE-HDR 14의 수용량은 250개이므로 다음 오류가 발생했다.

```text
resource 14 needs 286 unique tiles but capacity is 250
```

GUI 창에서는 백그라운드 작업 중 이 지점이 장시간 멈춘 것처럼 보일 수 있었다.

## 수정

- 리소스 12와 14는 미사용 BE-HDR 데이터에 패킹하지 않는다.
- 12번 수정본은 실제 런타임 프레임 00으로 이관한다.
- 14번 수정본은 실제 런타임 프레임 02~11로 분할 이관한다.
- 12번 수정본이 변경될 때마다 frame 00 수정본을 새로 생성하여 오래된 파일이 남지 않게 했다.

## 검증

14번 수정본을 대상으로 GUI의 런타임 처리 순서인 export → map-resource14 → apply를 재현했다.

- 완료 시간: 약 2.67초
- 오류 없음
- 출력 DAT 생성 확인
