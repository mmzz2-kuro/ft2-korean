# PS1 오프닝 스크린샷 검증과 V3 수정

## 스크린샷 확인

`screenshot/ps1-opening`의 7개 화면을 확인했다.

- 255, 257, 263, 265, 286은 Windows판 한글 이미지가 출력된다.
- 이름은 잘리지 않지만 이동 경계가 첫 번째 `성별` 행을 침범한다.
- 268 루루와 269 소피아는 글자 소실이 아니라 일본어 원본 전체가 출력된다.

## V3 좌표 수정

이름 이동 대상은 원본 0~47행으로 축소했다. 48행 이후의 설명은 원래 좌표를
그대로 사용하므로 이름을 8픽셀 내리면서 `성별` 행을 누락시키지 않는다.

## 268·269 정적 조사

V2 BIN에서 다시 추출한 268·269는 변환 목표와 일치한다. 원본 268·269의
타일맵 서명을 V2 BIN 전체에서 검색했지만 별도 복제본은 나오지 않았다. 정상적인
160×240 BE-HDR 소개 리소스 목록에도 별도의 루루·소피아 복제본은 없다.

따라서 현재 스크린샷의 일본어 화면이 어느 BIN 실행에서 나온 것인지 파일 단위로
대조한 뒤, 필요하면 실행 파일의 리소스 참조 경로를 추적해야 한다.
