# 엔딩 리소스 타일 용량 초과 처리

## 발생 원인

- 편집된 리소스 14는 가로 반전 재사용 후에도 고유 8×8 타일이 275개였다.
- 리소스 14에 배정된 실제 타일 슬롯은 250개이므로 기존 패커가 적용을 중단했다.
- 제한을 무시하면 다음 데이터 영역을 침범할 수 있으므로 오버플로 기록은 허용하지 않는다.

## 폐기한 처리

- 동일 타일과 가로 반전 타일을 공유한 뒤에도 275개가 필요했다.
- 근접 패턴 25개를 합치면 250개에 들어가지만 한글 획이 깨지는 것이 확인되어 이 방식은 폐기했다.
- 패커는 다시 무손실 전용으로 변경했으며, 용량을 넘으면 결과물을 만들지 않고 오류로 중단한다.

## 현재 편집본 조사 결과

- 대상: 리소스 14
- 가로 반전 공유 후 고유 타일: 275개
- 물리 용량: 250개
- 부족 슬롯: 25개
- 리소스 0~13은 각각 현재 섹터 수가 최소 필요 섹터 수와 같아, 앞 리소스의 빈 섹터를 14번에 넘기는 방법도 사용할 수 없다.
- 픽셀을 그대로 유지하려면 편집 화면의 행/열 위치를 8픽셀 타일 경계에 맞춰 고유 패턴을 줄이거나, 리소스 아카이브 전체 재배치와 로더 참조 분석이 필요하다.

`tmp/ss-fs2-ending-resource-workflow/test-output.bin`과 `test-export/resource-14-fitted.png`는 폐기된 손실 병합의 검증물이며 최종 패치에 사용하면 안 된다.
