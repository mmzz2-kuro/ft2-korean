# 42. 현재 확인된 미적용 항목

기준 빌드:

```text
output/ss-fs2-korean-speakers.cue
```

## 1. 팔레트형 시스템 UI 5개

| PS1 ID | SS ID | 상태 |
|---:|---:|---|
| 828 | 714 | 구조 차이, 팔레트 레이어별 후속 처리 |
| 1187 | 1073 | 구조 차이, 팔레트 레이어별 후속 처리 |
| 1188 | 1074 | 구조 차이, 팔레트 레이어별 후속 처리 |
| 1201 | 1087 | PS1 512×240 / SS 512×144, 화면별 수동 처리 |
| 1202 | 1088 | PS1 304×216 / SS 304×208, 최신 PS1판 변경 픽셀은 0 |

이 5개는 PS1판과 동일하게 팔레트 인덱스별 추출·편집·재삽입 방식으로 처리한다.

828(PS1) - 714(SS) 은 실제 사용하는 팔레트 레이어 인덱스 번호가 변경되었다.(254 -> 0)
그래서 별도의 처리를 하기 위해 0번 인덱스(검정색) 추출 시 데이터가 있는 항목은 흰색으로 변경하고 변경하지 않는 항목을 검정색으로 처리를 하도록 수정했다.

1202(PS1) - 1088(SS) 은 처리하지 않는다.(텍스트 없음)

## 2. 플랫폼 원본이 다른 일반 대사 4개 — 적용 완료

| 메시지 ID | 내용 | 상태 |
|---:|---|---|
| 1018 | 방향키 좌우/L1/R1 및 O버튼 조작 설명 | 플랫폼별 조작 표기 차이 가능성 |
| 5040 | 부잣집에 강도 예고장이 왔다는 대사 | SS 원문 기준 재번역 필요 |
| 5042 | 어느 부잣집인지 묻는 대사 | SS 원문 기준 재번역 필요 |
| 6093 | 수영복과 해변축제 대사 | SS 원문 기준 재번역 필요 |

네 항목은 SS 원문 확인 후 46단계에서 적용했다. `1018`은 SS의 L/R·C버튼 안내로 새로 렌더링했고 나머지 3개는 기존 PS1 한국어 PGM을 그대로 사용했다.

## 3. 1bpp 설명 UI 차이 2개 — 적용 완료

팔레트형 UI 5개와 별개로, 원본 설명 문구가 다른 1bpp UI 두 항목도 안전 빌드에서 제외되어 있다.

```text
PS1 930  -> SS 816
PS1 1053 -> SS 939
```

두 항목은 크기와 배치는 같고 글자 내용만 달랐다. 사용자 확인에 따라 PS1 한국어 설명을 그대로 사용했으며 44단계에서 적용을 완료했다.

## 4. 조사 예정

- 메모리 관리 화면의 게임명
- 시스템 오류·안내 문자열
- 플레이 중 새로 발견되는 미분류 일본어 화면
