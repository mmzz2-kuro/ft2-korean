# PS1 오프닝 직접 글꼴 렌더링과 루루·소피아 런타임 시트

## 글자 방식 변경

Windows BMP의 2배 해상도 글자를 축소하는 방식은 폐기했다. BMP에서는 번역 문구와
배경 문양만 활용하고, 글자는 `font/NanumSquareRoundB.ttf`를 사용해 PS1의 실제
160×240 좌표에 직접 렌더링한다.

- 이름과 본문을 각각 고정 크기와 고정 기준선으로 배치
- 모든 본문 행을 동일한 글꼴로 출력
- PS1 원본이 사용하는 글자 인덱스 1 사용
- 축소 과정이 없어 반 픽셀 굵기 차이와 행별 흔들림이 없음

## 루루·소피아의 실제 표시 데이터

리소스 268·269의 원본 스캔라인을 전체 `FS2_FILE.DAT`에서 검색한 결과, 리소스
306 안에 이미 풀린 두 화면이 함께 저장되어 있었다.

| 화면 | 리소스 306 상대 시작 | 폭×높이 | 행 간격 |
|---|---:|---:|---:|
| 루루 | `0x480` | 160×240 | `0x400` |
| 소피아 | `0x520` | 160×240 | `0x400` |

두 화면은 1024바이트 폭의 런타임 시트 안에 가로로 붙어 있다. 실제 오프닝에서는
268·269가 아니라 이 풀린 시트를 표시하므로 양쪽을 함께 수정해야 한다.

추가 도구 `scripts/ps1-fs2-patch-opening-runtime-sheet.py`가 변환된 268·269 PGM을
리소스 306의 해당 위치에 기록한다. GUI 빌드에도 이 단계가 포함되었다.

## 결과

- 출력: `output/patched-farland-saga-opening-ko-v4.bin`
