# PS1 엔딩 타이틀 실제 이미지 경로 조사

## 확정 사항

- 리소스 12의 일본어 영역을 포함한 타일 데이터를 전부 0으로 만든 진단 BIN에서도 인게임의 `時の道標`는 온전히 표시됐다.
- 따라서 리소스 12는 해당 인게임 화면의 실제 출력 원본이 아니다.
- 리소스 12의 일본어 영역(`130,29,63,15`)을 기준으로 BE-HDR 실루엣, 원문 타일, 팔레트 번호를 제거한 8bpp/4bpp 타일을 DAT 전체에서 검색했다.
- 모든 글자 또는 전체 문구가 일치하는 사본은 리소스 12 외에는 발견되지 않았다. 소수 타일 일치는 단순 획의 우연 일치다.
- EXE의 엔딩 관련 루틴 `0x801BEF90`은 리소스 `24`, `25`, `26`을 순서대로 로드해 VRAM 영역에 전송한다.
- 같은 루틴에서 리소스 12를 로드하는 코드는 확인되지 않았다.

## 리소스 24~26 전송 좌표

- 24: `(0,0,512,256)`
- 25: `(640,256,384,256)`
- 26: `(768,0,256,256)`, 원본 버퍼 `+0x200`

이들은 단순 BE-HDR 그림이 아니라 VRAM 텍스처 페이지 계열이다. 단순 4/8/16bpp 선형 해석에서는 완성된 문구가 나오지 않았고, 문자 단위 비교도 확정 가능한 후보를 만들지 못했다.

## 현재 결론과 다음 조사

리소스 12와 유사한 다른 **BE-HDR 이미지 사본은 없다**. 실제 엔딩 코드는 별도의 VRAM 페이지 리소스 24~26을 사용한다. 다음에는 함께 올라가는 CLUT과 엔딩 드로 프리미티브의 UV 좌표를 복원해 실제 화면이 참조하는 텍스처 사각형을 추출한다.

- `scripts/find-ps1-canonical-tile-copies.js`
