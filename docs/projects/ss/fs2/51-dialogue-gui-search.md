# 51. 대사 작업 GUI 번역 검색

## 변경 사항

`tools/dialogue_workflow_gui.py`의 대사 목록 위에 검색 영역을 추가했다. TSV 전체를 필터링해 숨기는 방식이 아니라 원래 행 순서를 유지하면서 검색 결과로 이동하므로, 기존 선택·수정·체크·저장 흐름에 영향을 주지 않는다.

## 검색 범위

- `한국어 번역`: `ko_text` 검색
- `메시지 ID`: 일반 메시지 ID와 finale 주소 검색
- `원문/메모`: `source_note`, `note`, `source` 검색
- `전체`: 위 필드와 참조 정보까지 통합 검색

`번역된 행만`은 기본으로 켜져 있다. 이 옵션을 끄면 한국어가 비어 있는 미번역 행도 메시지 ID나 메모로 찾을 수 있다. 검색은 영문 대소문자를 구분하지 않으며 한글·일본어 부분 문자열을 지원한다.

## 조작

| 조작 | 기능 |
|---|---|
| `Ctrl+F` | 검색창으로 이동하고 기존 검색어 선택 |
| `Enter` 또는 `F3` | 다음 결과 |
| `Shift+Enter` 또는 `Shift+F3` | 이전 결과 |
| `이전` / `다음` 버튼 | 결과 순환 이동 |

검색 결과로 이동하면 해당 행을 선택하고 목록을 자동 스크롤하며, 오른쪽 편집 영역과 마스크 미리보기도 함께 갱신한다. 상태 표시에는 현재 결과 번호, 전체 검색 결과 수, 메시지 ID가 나온다.
