# PS1 오프닝 캐릭터 소개와 Windows BMP 비교

## 결론

`tmp/SLPS-01903/opening-character-workflow/win-data`의 BMP 7개는 PS1 오프닝의
캐릭터 소개 리소스 7개와 각각 대응한다. Windows판에 이미 들어 있는 한글 문구와
배치를 PS1판 변환 원본으로 활용할 수 있다.

| 리소스 | 캐릭터 | Windows BMP | PS1 리소스 |
|---:|---|---:|---:|
| 255 | 아리스 | 320×480 | 160×240 |
| 257 | 라디슈 | 640×240 | 320×120 |
| 263 | 알 | 320×480 | 160×240 |
| 265 | 사라 | 320×480 | 160×240 |
| 268 | 루루 | 320×480 | 160×240 |
| 269 | 소피아 | 320×480 | 160×240 |
| 286 | 카린 | 320×480 | 160×240 |

모든 BMP는 대응 PS1 이미지의 가로와 세로가 정확히 2배다. 캐릭터명, 항목명,
설명뿐 아니라 배경에 반복되는 캐릭터별 장식 문구도 대응한다.

## 그대로 삽입할 수 없는 이유

- Windows BMP의 픽셀 팔레트 인덱스는 대체로 `10~21`이고, 리소스 257은 별도의
  인덱스 집합을 사용한다.
- PS1 BE-HDR 리소스는 캐릭터별로 서로 다른 8bpp 팔레트 인덱스를 사용한다.
- BMP를 단순히 절반 크기로 줄인 뒤 그 인덱스를 그대로 넣으면 PS1 런타임 CLUT에서
  색과 투명도가 다른 항목으로 해석된다.
- 축소한 BMP와 PS1 원본은 문장의 길이와 배치가 달라 전체 픽셀을 일대일 대응시켜
  팔레트 번호를 자동 치환할 수도 없다.

## 적용 방법

1. Windows BMP를 50%로 축소한다.
2. 채도가 있는 반복 장식과 무채색 한글 글자층을 분리한다.
3. PS1 원본의 일본어 글자층만 제거하고 기존 배경/장식층은 보존한다.
4. 축소한 한글 글자층을 PS1 리소스에서 사용하는 글자용 팔레트 계조에 맞춰 넣는다.
5. 각 리소스를 다시 타일 패킹하고 고유 타일 수가 원래 할당량을 넘지 않는지 검사한다.

Windows BMP는 따라서 단순 참고 이미지보다 유용하다. 번역문과 배치가 이미 완성된
공식 한글 그래픽 원본으로 사용하되, PS1용 축소·레이어 분리·팔레트 변환 과정이
필요하다.
