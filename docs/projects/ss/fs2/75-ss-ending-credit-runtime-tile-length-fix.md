# SS 엔딩 크레딧 런타임 타일 전송 길이 수정

## 인게임 증상

사용자 촬영 화면에서 다음 프레임만 글자 일부가 사라지거나 다른 크레딧 글자 조각과 겹쳤다.

- 14-09
- 14-10
- 18-05
- 19-03
- 20-04
- 20-05
- 21-03

나머지 프레임은 정상 출력됐다.

## 원인

BE-HDR 헤더 offset 0x08은 런타임으로 전송할 타일 데이터의 끝 위치다.

계산식:

    header[0x08] = 0x10 + tileCount * 64

기존 확장 패커는 섹터 할당과 PNT 타일맵만 확장하고 이 필드를 원본 값으로 남겼다. 그 결과 원본 최대 타일 번호를 넘는 타일은 VRAM에 전송되지 않았고, 해당 VRAM 위치에 남아 있던 다른 글자 타일이 표시됐다.

깨진 프레임과 원본 최대 번호 초과가 정확히 일치했다.

| 리소스/프레임 | 원본 최대 타일 | 새 프레임 최대 타일 |
|---|---:|---:|
| 14-09 | 243 | 269 |
| 14-10 | 243 | 285 |
| 18-05 | 175 | 210 |
| 19-03 | 123 | 145 |
| 20-04 | 175 | 196 |
| 20-05 | 175 | 207 |
| 21-03 | 109 | 157 |

## 수정

다음 두 패커가 재패킹한 고유 타일 수에 맞춰 header[0x08]을 갱신하도록 수정했다.

- scripts/ss-fs2-expand-ending-credits.js
- scripts/ss-fs2-palette-layer-resource.js

최종 전송 타일 수:

| 리소스 | header[0x08] | 타일 수 |
|---:|---:|---:|
| 14 | 0x4790 | 286 |
| 15 | 0x69D0 | 423 |
| 16 | 0x1C50 | 113 |
| 18 | 0x34D0 | 211 |
| 19 | 0x2490 | 146 |
| 20 | 0x3410 | 208 |
| 21 | 0x2790 | 158 |
