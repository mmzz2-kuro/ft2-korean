# PS1 오프닝 수동 PNG 타일 초과 처리

## 원인

수정된 269 PNG에는 146개의 회색 RGB 값이 있었다. 편집 프로그램에서 배경 문양과
글자 가장자리를 다시 샘플링하면서 8×8 타일의 중복이 줄었고, 431개의 고유 타일이
생겨 389개 할당량을 42개 초과했다.

## 268·269 처리 변경

루루와 소피아는 실제 게임에서 리소스 306의 풀린 8bpp 시트를 사용한다. 따라서
268·269 BE-HDR 패킹은 완전히 생략하고 수동 PNG를 리소스 306에 직접 기록한다.
이 경로에는 고유 타일 개수 제한이 없으며 PNG의 전체 형태를 유지할 수 있다.

## 나머지 리소스

255, 257, 263, 265, 286은 기존 BE-HDR을 사용하므로 고유 타일 제한이 있다.
사용자 PNG를 팔레트 인덱스로 변환한 뒤 용량을 넘는 경우 글자 영역 아래의 배경
타일만 가장 가까운 기존 타일과 통합한다.

현재 286은 12타일을 초과했다. `y >= 152`의 배경에서 1~2픽셀만 다른 타일 12개를
통합해 정확히 453개 용량에 맞췄으며 글자 영역은 변경하지 않았다.
