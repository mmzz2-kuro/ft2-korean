# PS1·SS 엔딩 성우 크레딧 리소스 비교

## 확인 결과

PS1판 `FS2_FILE.DAT`에도 SS판과 같은 엔딩 성우 크레딧 리소스가 있다.

| 리소스 | 내용 | 시작 섹터 | 할당 섹터 | 크기 | 타일 데이터 오프셋 |
|---:|---|---:|---:|---:|---:|
| 14 | 성우 캐스팅 첫 화면 | 204 | 9 | 320×240 | `0x970` |
| 15 | 성우 캐스팅 다음 화면 | 213 | 15 | 320×240 | `0x970` |

PS1 원본 `ps1/SLPS-01903/FS2_FILE.DAT`과 SS 원본 Track 1의 리소스 할당
영역을 비교한 결과, 14번과 15번 모두 바이트 단위로 완전히 동일하다.

## 최신 PS1 패치 확인

`output/patched-farland-saga-logo.bin`에서 LBA 223의 최신 `FS2_FILE.DAT`을
추출해 비교했다.

- resource 14: PS1 원본과 완전 동일, 변경 바이트 0
- resource 15: PS1 원본과 완전 동일, 변경 바이트 0

따라서 최신 PS1 패치에도 이 성우 크레딧 화면은 아직 한글 이미지로 교체되어
있지 않다. PS1의 한글화 결과를 SS에 복사하는 방법은 현재 사용할 수 없다.

## 용량 관계

PS1과 SS가 같은 리소스 데이터를 사용하므로 resource 14의 250타일 용량 제한도
동일하다. 현재 SS 편집 PNG가 요구하는 무손실 고유 타일 275개 문제는 PS1
리소스를 가져오는 것만으로 해결되지 않는다.

조사용 추출 파일은 `tmp/ps1-ending-check/`에 남겼다.
