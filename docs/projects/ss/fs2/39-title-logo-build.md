# 39. 타이틀·로고 통합 빌드

## 적용 결과

최신 PS1 통합판의 로고 리소스 2개를 34단계 빌드 위에 누적했다.

- PS1 `251` → SS `222`, LBA `8875`, 39섹터
- PS1 `288` → SS `259`, LBA `10271`, 39섹터

`251→222`는 원본 완전 동일 조건으로 이식했다. `288→259`는 화면 구조, 팔레트, 타일 데이터 위치, 할당 크기가 모두 같은 것을 확인한 후 전체 320×240 로고 화면으로 교체했다.
