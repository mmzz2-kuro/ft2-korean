# 43. 미적용 1bpp UI 2개 SS 원문 추출

## 추출 결과

현재 통합판에서 아직 변경되지 않은 SS 리소스 `816`, `939`의 288×64 1bpp 마스크를 직접 추출했다.

- 추출 도구: `scripts/ss-fs2-export-ui-mask.js`
- 리소스 816: LBA `18869`, 2섹터
- 리소스 939: LBA `19115`, 2섹터

## SS 리소스 816 원문

```text
動きやすいように設計された闘技用の服。
```

직역:

```text
움직이기 쉽도록 설계된 격투용 옷.
```

PS1판 작업표에는 `사라가 장비가능 / 방어력 +20`이 추가되어 있지만 SS 화면에는 해당 문장이 없다. SS 원문 기준 번역을 사용해야 한다.

## SS 리소스 939 원문

```text
聖なる力で、毒・眠りなど味方の体力
以外のあらゆる状態を回復させる。
レベルが上がると効果範囲も広くなる。
```

의미:

```text
성스러운 힘으로 독·수면 등
아군의 체력을 제외한 모든 상태를 회복시킨다.
레벨이 오르면 효과 범위도 넓어진다.
```

여기서 `体力以外`는 체력 자체를 회복하지 않고 상태 이상을 회복한다는 뜻이다. PS1 번역의 `기절 제외` 표현은 SS 원문에는 직접 나타나지 않는다.
