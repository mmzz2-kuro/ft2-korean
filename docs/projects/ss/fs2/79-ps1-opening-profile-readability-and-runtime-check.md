# PS1 오프닝 소개 화면 가독성 수정과 실행 리소스 확인

## 사용자 확인 결과

- 첫 변환판은 한글 획의 가독성이 낮았다.
- 큰 캐릭터명의 윗부분이 표시 영역에 잘렸다.
- 루루(268), 소피아(269)는 게임에서 적용되지 않은 것으로 보였다.

## 정적 확인

완성 BIN에서 `FS2_FILE.DAT`를 다시 추출한 결과, 리소스 268과 269에는 변환한
한글 픽셀이 손실 없이 들어 있었다. 전체 리소스 테이블에서 정상적인 160×240
BE-HDR 소개 화면은 255, 263, 265, 268, 269, 286뿐이고, 같은 규격의 별도 복제
리소스는 발견되지 않았다.

따라서 268·269가 계속 일본어로 표시되는지, 아니면 한글 획이 표시 팔레트에서
사라진 것인지 실제 화면을 구분해서 확인할 필요가 있다.

## 변환 수정

- 2×2 다수결 축소를 글자 최대 커버리지 축소로 변경했다.
- 글자는 각 PS1 원본에서 이미 사용되는 단색 글자 인덱스 1로 출력한다.
- 큰 이름의 원본 0~51행만 PS1 좌표에서 8픽셀 아래로 옮겼다.
- 설명 첫 줄은 이동 대상에서 분리해 잘리지 않도록 했다.
- 269의 용량 조정은 글자 밖 배경에서 1픽셀 차이 타일만 통합한다.

## 시험 결과

7개 모두 고정 리소스 할당량 안에서 패킹되었다. 출력 시험판은
`output/patched-farland-saga-opening-ko-v2.bin`이다.
