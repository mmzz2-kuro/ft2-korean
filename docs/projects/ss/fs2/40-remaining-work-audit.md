# 40. 최신 PS1 통합판 기준 잔여 작업 점검

## 변경 리소스 전수 비교

PS1 원본 `FS2_FILE.DAT`와 `output/patched-farland-saga-logo.bin`에서 추출한 최신 DAT를 리소스 경계별로 비교했다.

- 변경 리소스 표기 수: 431
- 변경 범위:

```text
251, 288,
811-1147,
1151-1178,
1181-1189,
1191-1201,
1203-1213,
4278-4302,
4451,4453,4455,4457,4459,4461,4463,4465
```

## 분류

- `251`, `288`: 타이틀·로고. 39단계에서 적용 완료.
- `811..1213` 사이 변경: 이름 테이블, 1bpp 설명/도움말/날짜 UI, 8bpp 타일형 UI. 안전 대응분은 적용 완료.
- 이 구간에서 구조가 다른 5개는 37단계 결정에 따라 팔레트 레이어 방식으로 후속 처리.
- `4278..4302`: 72×48 8bpp 대화 화자명 25개다. 최초 점검에서 상위/중첩 범위로 오분류했으며, 41단계에서 SS `4164..4188` 대응을 확인하고 적용했다.
- `4451` 이후의 큰 범위도 여러 하위 변경 영역을 포괄해 함께 달라진 상위 경계다. 신규 번역 항목이 8개 추가된 의미가 아니다.

따라서 최신 PS1 DAT에서 확인되는 독립적인 한글화 자산 계열은 대사, finale, 이름, 1bpp UI, 8bpp UI, 로고, 대화 화자명 범위로 정리된다.

## 다음 우선순위

### 1. SS 실행 파일 내부 시스템 문자열

DAT 외부에 남은 문자열을 조사한다.

- 저장 데이터 제목/설명
- 메모리 관리 화면에 표시되는 게임명
- 오류 및 시스템 안내 문구
- 실행 파일에 직접 포함된 Shift-JIS 문자열

PS1판에서는 저장 메타데이터 문구가 실행 파일 내부에 존재했으며 CP932 제약 때문에 한글 직접 치환이 어려웠다. SS판에서는 해당 문자열 위치와 실제 표시 경로를 별도로 확인해야 한다.

### 2. 전체 화면 미번역 점검

실기 또는 에뮬레이터 진행 중 남는 일본어를 화면별로 기록한다. 알려진 예외 UI 5개와 새로운 미분류 항목을 구분한다.

### 3. GUI/배포 빌드 통합

조사와 개별 빌드가 끝나면 현재 스크립트를 GUI 작업 흐름에 연결한다.

- 원본 SS BIN/CUE 검증
- 번역 TSV/PNG 선택
- 대사 reveal 확장
- UI, 이름, 로고 누적 적용
- EDC/ECC 재계산
- 최종 CUE/BIN 및 패치 파일 생성

## 결론

예외 UI 5개를 제외하면 다음 기술 조사 대상은 **SS 실행 파일 내부 시스템 문자열과 저장 데이터 표기**다. 그 후 전체 플레이 점검과 GUI 통합으로 넘어간다.
