# 37. 예외 UI 5개 팔레트 레이어 방식 후속 처리

## 결정

PS1/SS 원본 구조가 다른 다음 5개 리소스는 현재 자동 이식 범위에서 제외한다.

```text
PS1 828  -> SS 714
PS1 1187 -> SS 1073
PS1 1188 -> SS 1074
PS1 1201 -> SS 1087
PS1 1202 -> SS 1088
```

전체 리소스 복사, 전체 픽셀 차이 합성, 손실 타일 병합은 사용하지 않는다. 추후 PS1판에서 사용한 것과 같은 방식으로 각 팔레트 인덱스 레이어를 분리하여 처리한다.

## 후속 작업 방식

1. SS 원본 리소스를 raw palette index 화면으로 추출한다.
2. 글자와 효과에 사용되는 팔레트 인덱스를 레이어별로 분리한다.
3. 각 레이어를 실제 한글 영역만 편집한다.
4. 편집 레이어를 SS 원본 인덱스 화면에 다시 합성한다.
5. SS 고유 타일맵과 타일 용량을 기준으로 재패킹한다.
6. 팔레트 애니메이션과 색상 전환 상태를 화면별로 확인한다.
7. 무손실 용량을 넘는 경우 해당 화면 전용 타일 재사용 방식을 별도로 설계한다.

PS1 작업 참고 자료는 다음 위치에 남아 있다.

- `tmp/SLPS-01903/be-hdr-ui-workflow/palette-layer/`
- `tmp/SLPS-01903/be-hdr-ui-workflow/red-layer/`
- `tools/be_hdr_red_layer_workflow_gui.py`

## 현재 빌드 기준

이 5개가 미적용된 상태를 정상 기준으로 삼는다.

```text
output/ss-fs2-korean-behdr-ui-latest.cue
output/ss-fs2-korean-behdr-ui-latest.bin
```

게임에서 해당 화면에 일부 일본어가 남는 것은 알려진 미적용 사항이다.

## 다음 주 작업

예외 UI 작업은 보류하고, 다음 주 작업은 PS1 최신 통합판에 포함된 타이틀/로고 이미지 리소스를 SS판에 대응시키는 조사로 진행한다. PS1 로고 작업의 주 대상은 리소스 `251`, `288`이며 보조 후보로 `287`, `300`이 기록되어 있다.
